# SousaVet

Projeto do Hospital Veterinário do Campus Sousa, para digitalizar e consultar fichas veterinárias históricas em papel. O SousaVet complementa o SimplesVet.

- [INTENT](docs/INTENT.md) apresenta o propósito, o escopo e as decisões pendentes.
- [PLAN](docs/PLAN.md) organiza as SPECs e a sequência das Issues.
- [AGENTS.md](AGENTS.md) orienta o desenvolvimento e a tutoria com Claude Code.
- [Desafios](desafios/README.md) descreve a validação pedagógica.
- [Gestão de alterações](skills/change-management.md) define como solicitar e registrar mudanças.

A Issue 001 entrega a configuração do ambiente e as instruções de instalação, escritas pelo estudante.
