# SousaVet
SousaVet — Sistema de Gestão e Controle de Fichas Clínicas do Hospital Veterinário do Instituto Federal do Sertão Pernambucano (IFSertãoPB) – Campus Sousa, destinado ao registro, organização e gerenciamento das informações relacionadas aos pacientes, tutores, consultas e atendimentos médico-veterinários realizados pela instituição.
